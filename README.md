# NeuroTraceR

[NeuroTraceR Logo](./neuro-tracer/public/Logo.png)

A local-first, customisable workspace for creating printable tracing books, handwriting exercises, and mindfull illustration decoration.

Print of multiple pages/cards of passage you like, then trace them out with your favourite fonts and let the ravens guide you :)
